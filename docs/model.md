# 模型与求解方法

第一阶段按用户周期电量Ek=ΔtΣPpre构建统一电量份额U，外部总电量为Eg=ΔtΣ(P_rigid−P_renewable)+ΣEk。令T为时段数，有：

```text
U_t = [2 Eg/T + Δt (ΣP_renewable,t − ΣP_rigid,t)] / (Eg + ΣEk)
UG_t = 2/T − U_t
G0_t = Eg UG_t / Δt
```

再最小化Σalpha²，L=U+alpha，逐用户Σ_t alpha=0、逐时Σ_k Ek alpha=0，0≤L≤1。网络采用下游功率求和及LinDistFlow，并施加有功、电压和交换界。

响应为PDR=Ek(L+ξ)/Δt，ξ满足逐时盒界、Σ_t ξ=0、L+ξ≥0和Σ_t ξ²≤−ln(r)/β。四档阈值单调不减，升档收缩集合。先检查集合非空。

第二阶段外部交换固定为G0。每个响应情景可独立优化储能功率、模式和电量，期末电量等于初值。运行模型d=0；诊断模型允许零和用户时移d并加ρΣd²惩罚。只有运行不可行已证实才诊断升档，诊断结果不可直接执行。

## 连续等价性

效率为1、吞吐成本cs≥0时，将同一时段的充放电功率同时减去min(Pch,Pdis)，净注入、SOC变化和网络状态不变，两功率仍满足上下界且至少一个为0，成本不增加。因此连续模型与带互斥模式整数变量的模型具有相同可行性和最优成本。该变换逐情景成立，不能推广到有损效率、负成本、切换费用和最小开停时间。

## 全局检查

精确连续等价模型写为Ay≤b+Bξ、Cy=e+Fξ。Phase-I可行性违反量的对偶具有有界乘子，对ξ与乘子共同最大化得到全域违反上界。成本通过连续凸内层的原始可行性、站立性和互补条件进行全局最大化。使用Gurobi NonConvex=2，不把二次不确定集误当作整个问题都是凸的。

有限情景可行不能证明整个集合可行；一个集合内的已证实不可行情景可以否定全域可行性。最大化问题的全局上界用于验证，候选点重新检查后才作为反例。时间不足返回unverified。

仅T=2时，ξ=(a,−a)，二次预算和盒约束精确化成a的区间。连续等价调度的最优值关于右端参数是凸函数，最大值可以在区间笛卡尔积顶点取得。默认K≤6时使用这个精确分支；它不是对一般椭球做端点采样。设置two_period_vertex_limit=0可关闭。

本实现是一个有明确物理边界的研究用优化工具。输出保存完整参数、求解状态、成本界、逐情景结果和可选矩阵，便于复核和扩展。
